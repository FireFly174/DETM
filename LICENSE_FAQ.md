# License FAQ

This is a plain-language summary of DETM licensing. It is not legal advice.
The legally binding text is in `LICENSE` and commercial agreements.

## What is the model?

DETM uses a dual-license model:

- `PolyForm-Noncommercial-1.0.0` for non-commercial use
- commercial license for commercial use

## Can I use DETM for research and learning?

Yes. You can use, modify, and run DETM under non-commercial terms.

## Can I use DETM commercially?

Yes, but only under a separate commercial license from the copyright holder.
Commercial use is not allowed under the non-commercial license.

## Do I need to disclose source code for non-commercial use?

No mandatory copyleft/source-disclosure requirement is imposed by the license
model for non-commercial use in this repository.

## Is this "MIT + commercial"?

Not exactly. MIT always allows commercial use, so MIT cannot enforce
"non-commercial free, commercial by agreement".

This repository uses a source-available non-commercial license plus
separate commercial licensing.

## When do I need a commercial license?

You typically need a commercial license if you want to:

- use DETM in paid products/services;
- use DETM in internal commercial operations;
- ship DETM inside proprietary software for commercial customers.

## Do contributors keep rights to their contributions?

Contributors keep copyright to their own contributions unless stated otherwise.
By contributing, they agree to contribute under the project licensing model.

## Where to request commercial terms?

See `COMMERCIAL_LICENSE.md` and `SUPPORT.md`.
