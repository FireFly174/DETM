DETM — базовая спецификация модели
1. Общий обзор

DETM (Discrete Entropy-Time Model, дискретная энтропийно-временная модель) — это дискретная динамическая система, заданная на регулярной решётке.
Модель описывает локальный перенос скалярной величины («энергии») с ограничениями, накладываемыми локальной структурой среды, энтропийным подавлением и внутренним временем (латентностью).

Цель модели — исследование возникновения устойчивых, локализованных и долгоживущих инвариантных структур, которые появляются исключительно из локальных правил взаимодействия, без задания объектов, целей или глобальной координации.

2. Пространство и время
2.1 Пространство

Система определена на двумерной решётке Ω размером N×N.
Каждая ячейка решётки идентифицируется позицией r, принадлежащей Ω.

Связи локальные: каждая ячейка взаимодействует только с ближайшими соседями (тип окрестности задаётся отдельно).

Граничные условия могут быть:

фиксированными,

открытыми,

периодическими (топология тора).

2.2 Время

Время дискретное и задаётся целыми шагами t = 0, 1, 2, …
Все обновления вычисляются относительно глобального тика.

При этом каждая ячейка может обладать собственным внутренним временем, отличающимся от глобального тика (см. раздел 5).

3. Переменные состояния

Каждая ячейка r в момент времени t имеет следующий набор состояний.

3.1 Энергия

E(r,t) ∈ [0, 1]

Энергия — скалярная величина, которая локально переносится между соседними ячейками.
Энергия является сохраняемой величиной (с учётом граничных условий).

3.2 Энтропийное подавление

S(r,t) ≥ 0

S — локальная скалярная величина, описывающая подавление переноса энергии.
Она зависит от:

отклонения энергии E(r,t) от опорного уровня E₀;

локальной неоднородности (разностей энергии с соседями).

S не является термодинамической энтропией.
Это эффективный структурный фактор, ограничивающий транспорт.

3.3 Внутреннее время (латентность)

τ(r,t) ≥ 0

τ описывает локальную задержку реакции ячейки.
Чем больше τ, тем медленнее через ячейку может проходить перенос энергии.

Внутреннее время не изменяет глобальный тик, а модулирует локальную динамику.

4. Потоки энергии
4.1 Базовый поток

Для каждой пары соседних ячеек (r, r′) определяется базовый поток энергии, пропорциональный разности энергий между ними.

Интенсивность потока масштабируется параметром проводимости κ > 0.

4.2 Эффективный поток

Реальный (эффективный) поток подавляется локальной структурой среды и внутренним временем.

Эффективный поток уменьшается:

при росте S(r,t);

при росте τ(r,t).

Таким образом:

перенос всегда локален;

перенос всегда ограничен;

в структурно сложных областях поток замедляется нелинейно.

5. Правило обновления энергии

Энергия в каждой ячейке обновляется по дискретному уравнению непрерывности:

Энергия в момент t+1 равна энергии в момент t минус сумма эффективных потоков, уходящих из ячейки к её соседям.

Это правило:

сохраняет суммарную энергию системы;

обеспечивает строгую локальность взаимодействий;

предотвращает неограниченное распространение возмущений.

6. Инвариантные структуры

Инвариантная структура определяется операционально, через наблюдаемые свойства динамики.

Структура считается инвариантной, если она удовлетворяет следующим условиям:

Устойчивость
Структура сохраняется на длительных временных интервалах.

Локализация
Структура занимает ограниченную область решётки.

Фазовая согласованность
Внутренняя динамика структуры характеризуется устойчивым периодом T.

Робастность
Структура сохраняет идентичность при умеренных внешних возмущениях.

Инварианты не задаются явно и не кодируются в правилах модели — они возникают эмерджентно.

7. Минимальность модели

Следующие элементы считаются необходимыми для возникновения инвариантов:

дискретная решётка;

скалярное энергетическое поле;

локальный перенос энергии с ограниченной пропускной способностью;

энтропийное подавление переноса;

внутренняя временная латентность.

Удаление любого из этих элементов разрушает наблюдаемое формирование устойчивых структур.

8. Область применимости

Данный документ описывает только базовые динамические правила модели DETM.

Любые интерпретации, аналогии, уровневые описания, сопоставления с физикой, биологией, когнитивными или инженерными системами рассматриваются отдельно и не входят в спецификацию модели.
