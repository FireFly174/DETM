# e как естественный шаг масштаба и границы (рабочая гипотеза)

## Статус

Исследовательская карточка. Не изменяет канон L0 и не вводит физические константы в ядро DETM.

---

## 1) Контекст и термины

В этом документе `e` означает математическую константу `e ≈ 2.71828`, а не элементарный заряд `e = 1.602176634×10^-19 Кл`.

Рабочая интуиция:
- `e` может быть естественным шагом коарсинга;
- переход через одну "единичную" границу может иметь экспоненциальный вид;
- в логарифмической шкале это делает переходы между уровнями линейными.

---

## 2) Гипотеза масштаба (e-step)

Если уровни связаны как:

`L_(n+1) = e * L_n`,

то уровень становится координатой:

`n = ln(L / L0)`.

Следствие:
- один шаг уровня равен `+1` в `ln L`;
- коарсинг описывается одинаковыми шагами в лог-шкале;
- уравнения эволюции удобнее писать через `dX / d(ln L)`, а не через `dX / dL`.

Эквивалентная запись для шага "вглубь":

`L_(n+1) = L_n / e`  =>  `ln L_(n+1) = ln L_n - 1`.

---

## 3) Гипотеза границы (экспоненциальное прохождение)

Для потока энергии через границу:

`dE/dx = -kE`  =>  `E(x) = E0 * exp(-kx)`.

Если `k=1` и "толщина единичной границы" `x=1`, то:

`E_out = E_in / e`.

Интерпретация для DETM:
- граница рассматривается как слой ослабления/преобразования, а не как идеальная линия;
- переход между соседними слоями можно параметризовать экспоненциально.

---

## 4) Связь с инвариантами

Если компонент `X` масштабируется как `X ~ L^a`, то при `L_(n+1)=e*L_n`:

`X_(n+1) = exp(a) * X_n`.

Для шага "вглубь" (`L_(n+1)=L_n/e`):

`X_(n+1) = exp(-a) * X_n`.

В лог-переменных:

`ln X_(n+1) = ln X_n + a`.

Практический смысл:
- неинвариантные компоненты систематически дрейфуют по `n`;
- устойчивые инварианты видны как компоненты с малым дрейфом в лог-шкале;
- e-coarsening можно использовать как оператор фильтрации по устойчивости.

---

## 5) Почему это ведёт к O(1)-представлению

Переход к безразмерным переменным (`n = ln(L/L0)`, нормировка времени/энергии) позволяет:
- работать с коэффициентами, не зависящими от абсолютного масштаба;
- описывать переходы между уровнями постоянными множителями;
- переносить динамику в режим "константной сложности на шаг уровня" (операторный `O(1)` на тик/уровень в пределах валидности).

Важно: это не "магическая гарантия" для всех режимов. При фазовых переходах и несамоподобии нормировка может разрушаться.

---

## 6) Как проверять гипотезу

1. Ввести две шкалы коарсинга: произвольный фактор `k` и `k=e`.
2. Сравнить стабильность инвариантов при одинаковом числе лог-шагов (`ln L`-горизонт).
3. Измерить дрейф признаков в лог-переменных:
   - спектральные пики,
   - граничные потоки,
   - долю refinement-событий.
4. Проверить, уменьшается ли разброс коэффициентов межуровневых операторов (признак приближения к `O(1)`-описанию).

Критерий опровержения:
- `k=e` не даёт выигрыша в устойчивости/переносимости коэффициентов относительно соседних факторов `k`,
- либо лог-шкала не снижает межуровневой дрейф.

---

## 7) Ограничения и совместимость с каноном

- Это рабочая гипотеза по шкалированию, а не утверждение о фундаментальных константах Вселенной в DETM.
- Канонический инвариант `E in [0,1]` остаётся неизменным.
- Любая реализация должна проходить через существующие контракты уровней и refinement/coarsening.
