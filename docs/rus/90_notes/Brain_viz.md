MVP за 7 дней: «Прозрачный мозг» (реально достижимо)
Что считаем готовым

JSON/SQLite база “инварианты + связи”

автоматический цикл run → score → keep/drop

граф-визуализация (первый вариант): интерактивный HTML (или Gephi)

zoom-уровни: Ln отображаются как агрегации (хотя бы 2–3 уровня)

галерея кадров/снапшотов: “как граф рос”

День 1. Схема данных (самое важное)

Артефакт: graph_store.{json|sqlite} + schema.md

Минимальные сущности:

Node (инвариант / O(1)-оператор)

id

level (Ln)

signature (хэш/вектор признаков)

validity_box (границы применимости)

stability (выжил при коарсенинге M раз)

last_seen_tick

Edge (переход/сопряжение)

src, dst

transform (тип: refine/coarsen/teleport/merge)

support (сколько раз подтверждалось)

freq_ratio (делимость/почти делимость)

Event (журнал)

tick

inputs (возмущение)

metrics (violations, residual, etc.)

created_nodes, strengthened_edges

День 2. Автопрогон и логгер

Артефакт: runner.py + папка runs/YYYYMMDD_HHMM/

запускаем N эпизодов

на каждом: возмущение → эволюция → commit → метрики

пишем только то, что нужно графу (не тонны сырых данных)

День 3. Скоринг и “естественный отбор”

Артефакт: score.py + правила “роста узлов”

Простейшие правила (работают сразу):

если оператор пережил coarsen по времени и сохраняет структуру → stability++

если частоты “не делятся” и пришлось refine → это граница применимости (обновляем validity_box)

если один и тот же тип реакции повторился K раз → создаём/укрепляем узел

если узел не встречается T тиков → “истончаем” (decay)

День 4. Агрегация уровней (zoom)

Артефакт: coarsen_graph.py

Минимальный zoom:

Ln-1 узлы группируются в Ln по:

похожести сигнатуры,

совместимости по частотам,

общему “порту” (одинаковые трансформы)

Это даст эффект:

отдаляешься → узлы сливаются в “мозговые доли”

приближаешься → распадаются на детали

День 5. Визуализация “прозрачного мозга”

Артефакт: brain_graph.html

Самый быстрый путь:

экспорт в GraphML → Gephi (красиво сразу)

или интерактив через pyvis / d3.js

Визуальные правила:

размер узла = stability

прозрачность = “уверенность” / support

цвет = level

толщина ребра = support

пунктир = “почти-делимость / конфликт уровней”

клик по узлу → “карточка”: метрики, границы, последние эпизоды

День 6. “Клёвая картинка”: таймлапс роста

Артефакт: timelapse/ + сборка кадров

каждые X эпизодов сохраняем снапшот графа

делаем GIF/видео

это и будет тот режим: я просто смотрю как оно растёт

День 7. Полировка: авто-режим без тебя

Артефакт: autopilot.yaml + “кнопка запуска”

один конфиг задаёт:

частоту возмущений

бюджеты compute

правила coarsen/refine

частоту снапшотов

запускаешь вечером → утром смотришь “мозг”
