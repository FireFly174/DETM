# «Смысл», алфавиты уровней и LLM-mode (заметки)

Тема относится к **уровням выше L0** и/или оркестрации (ACGS). В текущем репозитории DETM она хранится как `90_notes`.

## 1) Смысл как межуровневая устойчивость

Операциональная гипотеза:

> «Смысл события = способность пережить подъём по уровням (коарсинг)».

То есть сигнал считается “значимым”, если он сохраняется при укрупнении описания и остаётся различимым в наблюдаемых инвариантах.

## 2) Алфавит уровня Σ_L

Каждый уровень `L` имеет свой “алфавит” примитивов/инвариантов `Σ_L`:
- выразимость уровня ограничена `|Σ_L|`
- новые смыслы требуют либо расширения алфавита, либо перехода на другой уровень представления

## 3) Перегрузка уровня и связь с fallback

Если “смысл” превышает ёмкость алфавита (`|Σ_L|` не хватает для различимости/композиции), то появляются признаки перегруза:
- рост нестабильности/ошибок
- рост частоты fallback (см. `Fall/Instab`)

Тогда:
- либо строится новый примитив (расширение `Σ_L`)
- либо включается детализация (fallback/subworld)

Связанные заметки:
- fallback/subworld: `docs/rus/90_notes/fallback_subworld.md`
- метрики перегруза: `docs/rus/90_notes/storage_neurons_subworld.md`

## 4) LLM-mode как “токен → возмущение → отклик”

Концептуальный режим:
- вход (токен) кодируется как нормированное внешнее воздействие на поле (injection)
- среда эволюционирует (внутренние тики, возможные subworld)
- выход — компактное считывание инвариантов/подписей (readout)

Важно: это **интерпретация поверх L0**, а не замена динамики.
