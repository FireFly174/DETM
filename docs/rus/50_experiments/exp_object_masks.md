# Маска объекта и диагностика границы

## Зачем это нужно

В данных модели есть только поля (`E`, потоки `J`, энтропийные прокси, `τ`), но в рассуждениях постоянно фигурируют «объекты», «аттракторы», «структуры».

Чтобы сравнивать прогоны и строить метрики, нужно **операционально определить объект** как выделяемую область решётки (маску) и считать наблюдаемые по этой области и её границе.

---

## Как построить маску (варианты)

Ниже — минимальные подходы, которые можно комбинировать:

1) По энергии `E` (порог)
- `M = (E > mean(E) + k * std(E))`

2) По границе через градиент
- `M = (|∇E| > θ)` как карта фронтов; затем выделение области (например, заполнение контуров)

3) По активности/потоку
- `M = (|J| > θ)` для «живых» областей, где идёт перенос

4) По вихревости
- `M` вокруг ядер `curl(J)` (если наблюдаются вихри/орбиты)

Почти всегда полезно иметь две маски:
- «жёсткую» бинарную `M` (для компонент/площади),
- «мягкую» `w` (например, нормированная энергия) для взвешенных метрик.

---

## Граница маски

Граница `∂M` нужна для оценки обмена с окружающей средой и для «интерфейсных» гипотез.
Практически:
- `∂M` можно получить как морфологическую границу бинарной маски,
- либо как множество ячеек `M=1`, имеющих хотя бы одного соседа `M=0`.

---

## Минимальные метрики

### Геометрия/идентичность
- `area(M)`, `r_eff` (эффективный радиус), центр массы/центроид
- `n_components` и распределение размеров компонент
- стабильность формы: `corr(E(t), E(t+Δt))` внутри `M`

### Потоки по границе
- `J_boundary`: средний `|J|` на `∂M`
- `E_flux_in/out`: прокси вход/выход энергии через `∂M` (по направлению `J` и нормали)
- циркуляция `∮ J·dl` (признак орбитальности/замкнутости)

### Внутренняя динамика
- `J_inside`: средний `|J|` внутри `M` (различает «мёртвый» и «живой» объект)
- `curl_rms` внутри `M`

## Как использовать в экспериментах

- жизненный цикл: зарождение → стабилизация → взаимодействия → распад/переход режима;
- сравнение режимов и фазовых переходов (см. `docs/rus/50_experiments/exp_phase_map.md`);
- измерение скорости переноса внутри объекта и через границу (см. `docs/rus/50_experiments/exp_transfer_speed.md`).
