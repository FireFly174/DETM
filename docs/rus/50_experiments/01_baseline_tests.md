# Baseline Tests (DETM, RU)

Статус карточки:
- `status`: ready_for_execution
- `artifact_status`: pending run artifacts для текущего milestone
- `last_reviewed`: `2026-02-14`

Этот документ задает минимальный baseline набор экспериментов.

Цель:
- быстро проверить, что исследовательский контур рабочий end-to-end;
- не дублировать детальные инструкции из `exp_*`.

## B0. Репликация и детерминизм

Протокол:
- повтор одного и того же прогона с одинаковым `seed` и config.

Проверка:
- совпадают ключевые readout-артефакты (с учетом оговоренных допусков протокола).

Ссылки:
- `docs/rus/integration_contract.md`
- `docs/rus/50_experiments/legacy_data_formats.md`

## B1. Фазовая карта режимов (базовая)

Протокол:
- `docs/rus/50_experiments/exp_phase_map.md`

Проверка:
- режимы различимы по метрикам, а не только визуально;
- переходы между режимами наблюдаемы на сетке параметров.

Ключевые метрики:
- `J_tail`, `curl_rms`, `t_stable`, спектральные признаки.

## B2. Маска объекта и граница

Протокол:
- `docs/rus/50_experiments/exp_object_masks.md`

Проверка:
- маска стабильна на окне наблюдения;
- boundary-метрики дают информативный сигнал при взаимодействиях.

## B3. Перенос/лаги

Протокол:
- `docs/rus/50_experiments/exp_transfer_speed.md`

Проверка:
- lag-профиль интерпретируем и устойчив между seed;
- изменение условий среды влияет на lag ожидаемым образом.

## B4. Каналы и среда

Протокол:
- `docs/rus/50_experiments/exp_channels.md`

Проверка:
- ускорение/изменение согласования возникает только при наличии канала;
- при разрушении канала эффект исчезает.

## B5. Плотность и предел емкости

Протокол:
- `docs/rus/50_experiments/exp_density.md`

Проверка:
- фиксируется граница плотности устойчивых структур в заданных условиях.

## Формат итогового baseline отчета

Минимум:
1. Таблица по тестам B0-B5: `pass/fail/inconclusive`.
2. Ссылка на артефакты каждого теста.
3. Краткий список рисков интерпретации (что еще может ломать вывод).
