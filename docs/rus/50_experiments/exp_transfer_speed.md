# Скорость переноса энергии и лаг‑диагностика

## Цель

Оценить, **как быстро распространяется влияние** (энергия/изменения поля) внутри объекта и через его границу.
Это полезно для:
- диагностики устойчивых структур (статический vs динамический аттрактор),
- проверки роли асинхронности `τ` как ограничения скорости причинности,
- построения фазовых карт режимов.

Рекомендуется использовать вместе с выделением маски: `docs/rus/40_experiments/exp_object_masks.md`.

---

## Метод A: лаг‑корреляции (прокси задержки переноса)

1) Выберите опорную точку/область внутри объекта (центр массы, максимум `|J|`, ядро вихря).  
2) Для набора соседних точек `x1` считайте:
   - `corr(E(x0,t), E(x1,t+τ))` на окне времени,
   - `τ_max`, при котором корреляция максимальна.
3) Интерпретируйте `τ_max` как оценку задержки переноса между `x0` и `x1`.

Примечание: это «прокси», а не физическая скорость. Главное — сравнимость между режимами/параметрами.

---

## Метод B: потоковые прокси скорости

Минимальная оценка «скорости переноса» по данным полей:

- внутри объекта:
  - `v_eff = ⟨ |J| / (E + ε) ⟩_mask`
- на границе:
  - `v_boundary = ⟨ |J| / (E + ε) ⟩_∂mask`

где `ε` — маленькое число для стабилизации.

---

## Дополнительно: орбиты и периодичность

Если наблюдаются циркуляции:
- считайте циркуляцию `∮ J·dl` (по контуру/границе объекта);
- оценивайте период `T_orbit` через кольцевые средние (`ring_means`) и rFFT.

---

## Выходные артефакты (минимум)

- конфиг прогона + seed;
- компактные ряды: `E_mean(t)`, `mean(|J|)(t)`, (опционально) `signature(t)`;
- агрегированные метрики: `τ_max`‑профиль, `v_eff`, `J_tail`, `curl_rms`.

Сводка метрик: `docs/rus/40_experiments/metrics.md`.
