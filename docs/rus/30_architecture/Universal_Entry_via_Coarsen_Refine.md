2. Базовая абстракция
2.1 Состояние уровня

Для каждого уровня 
𝐿
L:

X_L = { fields, geometry, constraints }


где:

fields — поля (E, S, τ, J, …);

geometry — топология решётки;

constraints — допустимость оператора.

2.2 Операторы уровня

Для каждого уровня определяются два оператора:

Coarsening
(X_{L+1}, cache_L) = C_L(X_L)


схлопывает детали;

формирует эффективные величины;

сохраняет cache, необходимый для возможного восстановления.

Refinement
X_L' = R_L(X_{L+1}, cache_L, constraints)


восстанавливает допустимое, а не единственное микросостояние;

не является обратной функцией в строгом смысле;

контролируется метриками ошибки и допустимости.

3. Cache как канонический объект

cache_L — часть смысла, а не техническая деталь.

Он отвечает на вопросы:

почему именно так был выполнен coarsening;

какие степени свободы были отброшены;

как можно безопасно вернуться вниз.

Примеры cache:

индексы значащих клеток;

argmax / сегменты (аналог pooling);

Normalized State Representation (NSR);

карты ошибки / доверия.

4. Связь с CNN-прототипом (эмпирическое подтверждение)

Экспериментальный скрипт cnn_from_scratch_torch_v2.py подтверждает архитектурную состоятельность идеи:

Conv2DFromScratch
→ локальный оператор уровня (аналог L₀-динамики);

MaxPool2DFromScratch
→ coarsening с явным cache (argmax);

backward_manual()
→ прототип refinement:
восстановление распределения на мелком уровне
по подсказкам, а не по градиенту.

Важно:
backprop ≠ refinement,
но backprop является частным случаем передачи сигнала вниз.

5. Normalized State Representation (NSR)

NSR рассматривается как альтернативный cache + формат состояния.

Основные принципы:

хранится не вся решётка, а иерархия значащих элементов;

данные организованы от якоря (центра) наружу;

восстановление происходит послойно;

центр выбирается динамически (центр масс / аттрактора),
чтобы сохранить инвариантность к сдвигу.

NSR позволяет:

стартовать вычисление с любого уровня;

выполнять частичное refinement;

уменьшать стоимость хранения и визуализации.

6. Universal Entry Point

Универсальная точка входа определяется как:

возможность принять решётку на любом уровне L
и применить стандартный контракт coarsen/refine
без знания истории формирования уровня.

Следствия:

DETM становится навигацией по иерархии представлений;

ACGS управляет куда и насколько выполнять refinement;

визуализация и внешние плагины работают через тот же контракт.

8. Ограничения и предохранители

Coarsening не обязан быть обратимым.

Refinement не обязан восстанавливать “истину”.

Не все режимы допускают эффективное NSR.

Quality-метрики определяют границу допустимости.

Эти ограничения сохраняются намеренно,
чтобы система не схлопывалась в тривиальную интерпретацию.

9. Итог

Coarsen / Refine — не обучение и не оптимизация,
а протокол перехода между уровнями описания.

Cache — первичный объект архитектуры.

DETM получает универсальную точку входа на любом уровне.

Архитектура масштабируется:

вниз (детализация),

вверх (обобщение),

в сторону (внешние наблюдатели и плагины).

Ln+2 : частота изменения "объекта как целого"
Ln+1 : частота взаимодействий / реакций
Ln   : внутренняя частота инварианта (линейна по энергии)
Ln-1 : спектр микроколебаний
L0   : локальные флуктуации
