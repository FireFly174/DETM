# Радиус влияния аттрактора и пропускная способность границы

## Статус

Каноническая карточка механизма.

Данный документ вводит формальное понятие **радиуса влияния аттрактора**
и связанного с ним критерия **пропускной способности по границе**.

Карточка нужна для:

* формализации «масштаба мира» через границы (а не объём);
* определения мощности/throughput системы как потока через контур;
* переноса идей типа Кардашова в язык DETM (throughput вместо «доступа к источнику»).

---

## 1. Мотивация

В DETM важен не «объём пространства», а то,
какой поток может быть:

* принят системой,
* преобразован,
* распределён,
* и рассеян,

при сохранении устойчивости инвариантов.

Это естественно описывается **через границы**: потоки в DETM заданы полем `J`,
а взаимодействие с внешним миром реализуется через внешний контур.

---

## 2. Поток через границу

Пусть в пространстве (или на решётке) задано поле потока `J(r,t)`.

Определим **поток через замкнутую границу** `∂Ω`:

* в непрерывном виде:

```
Φ(∂Ω, t) = ∮_{∂Ω} J(r,t) · dS
```

* в дискретном виде (на решётке) это сумма нормальных компонент потоков
  по граничным рёбрам области `Ω`:

```
Φ(∂Ω, t) = Σ_{e ∈ ∂Ω} J_e(t)
```

Знак потока трактуется как:

* `Φ > 0` — нетто-отток из области,
* `Φ < 0` — нетто-приток в область.

---

## 3. Пропускная способность границы (boundary throughput)

Определим **пропускную способность границы** как устойчивую (усреднённую)
величину потока по времени:

```
Throughput(∂Ω) = ⟨ |Φ(∂Ω, t)| ⟩_t
```

Это ключевая величина вместо «мощности в ваттах»:

* она не зависит от того, что именно является источником,
* она измеряет способность системы пропускать динамику через себя,
* она напрямую связана с устойчивостью и обратной связью.

---

## 4. Радиус влияния аттрактора

Пусть аттрактор `A` локализован в некоторой области `Ω0`.

Рассмотрим семейство областей `Ω(R)` — расширение вокруг центра аттрактора.
Например, на решётке это квадраты или круги радиуса `R`.

Определим **радиус влияния** `R_A` как минимальный `R`,
при котором внешние потоки «компенсированы» относительно масштаба аттрактора.

Формально вводится через одно из эквивалентных условий.

### 4.1 Через насыщение потока

Если при росте `R` поток через границу стремится к плато:

```
Throughput(∂Ω(R)) → const  при  R → ∞
```

то `R_A` можно определить как радиус,
после которого изменение throughput мало:

```
|Throughput(R+ΔR) - Throughput(R)| < ε
```

То есть влияние аттрактора «не растёт дальше».

### 4.2 Через баланс притока/оттока

Если аттрактор устойчив, то на масштабе его влияния
приток и отток через границу компенсируются (в среднем):

```
⟨Φ(∂Ω(R_A), t)⟩_t ≈ 0
```

Это условие соответствует идее:
«на границе нет нетто-перекачки — система замкнута в среднем».

### 4.3 Через сравнение с “содержанием” аттрактора

В моделях, где вводится мера «содержания/массы/энергии» аттрактора `M_A`
(например, интеграл E по области, или другая инвариантная метрика),
можно определить `R_A` как радиус, на котором поток сравним с этой мерой:

```
Throughput(∂Ω(R_A)) ~ κ · M_A
```

`κ` задаёт масштабную конвенцию (аналог «единиц»).

---

## 5. Тип системы как throughput-уровень

Предложение (каноническая интерпретация):

> «Тип» системы/цивилизации — это не доступ к источнику,
> а **устойчивая пропускная способность через границу**.

То есть система типа X умеет:

* удерживать и перераспределять потоки масштаба X,
* не разрушая собственные инварианты.

В частности, «Type I» в такой трактовке:

* это достижение throughput масштаба планетарной границы,
* а не просто извлечение энергии.

---

## 6. Связь с механизмами DETM

### 6.1 Связь с границами subworld

Радиус влияния — это способ выбирать активные границы мира:

* активный мир определяется `∂Ω(R)`
* вычислительная стоимость зависит от длины границы и активности потоков

Это согласуется с принципом:
«размер мира = границы, а не объём».

### 6.2 Связь с links (внешние каналы)

Внешние связи (links) реализуют потоки через границы.
Throughput может измеряться как сумма вкладов links
плюс внутренние потоки на граничных рёбрах.

### 6.3 Связь с коарсенером

Коарсенер выбирает масштаб времени/уровень так,
чтобы throughput на выбранной границе был устойчиво представим:

* если потоки слишком быстрые/резкие → refinement
* если потоки сглажены → coarsen

---

## 7. Практическая метрика для экспериментов

Для фиксированного аттрактора:

1. выбрать центр `c`
2. задать семейство областей `Ω(R)`
3. на каждом тикe считать `Φ(∂Ω(R), t)`
4. усреднить `Throughput(R)`
5. найти `R_A` по критерию насыщения или баланса

Это даёт измеримую характеристику:

* «насколько далеко распространяется влияние»
* «какой поток удерживается на границе»

---

## 8. Инварианты карточки

1. Влияние измеряется потоком через границу
2. Радиус влияния определяется через семейство границ
3. Throughput — ключевая метрика типа системы
4. Границы важнее объёма
5. Механизм совместим с links / coarsener / refinement

---

## 9. Назначение документа

Карточка фиксирует канонический способ
определять масштаб системы через границы и потоки.

Используется для:

* формализации «типа цивилизации» в терминах throughput;
* выбора границ subworld и оценки их активности;
* построения метрик влияния аттракторов в DETM.
