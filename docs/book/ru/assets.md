# Assets (картинки/мемы) для книги

Эта книга — Markdown-черновик, поэтому картинки лучше хранить рядом с главами в `docs/book/ru/` и вставлять относительными ссылками.

Рекомендации:
- Держать файлы небольшими (сжимать).
- В тексте рядом с картинкой оставлять 1 строку, что именно она иллюстрирует (чтобы смысл сохранялся без картинки).

Заготовка для мема из обсуждения:
- положить файл как `docs/book/ru/nasha.jpg` (или `nasha.png`)
- ссылка в тексте: `![«Наша» — мем про внешние эффекты](nasha.jpg)`
