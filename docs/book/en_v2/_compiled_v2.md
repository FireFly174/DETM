## Where to start (short hook)

Imagine a bridge.

From outside it looks fine: traffic moves, reports are green, dashboard numbers grow.
But inside, the bridge stands only because load, joints, corrosion, maintenance, and tolerance are still under control.

Complex human systems break in the same way:
- language keeps working while causality is already broken,
- metrics keep growing while reality degrades,
- institutions protect capture rather than stability,
- the regime crosses a boundary and old optimization no longer converges.

This book is not a moral manifesto.
It is a diagnostic framework:
1. locate the failing level,
2. restore causality with a minimal operator,
3. move back from emergency to controlled adaptation.

Core idea:

> Most system conflicts are level-mismatch conflicts.

One actor talks about basis (L0), another about actions (L1), another about narratives (L2), another about rules (L3), and another about institutional power (L4/L5).

## Levels map (L0..L5)

The model uses six operational levels.

| Level | Question | Typical failure | Typical operator |
|---|---|---|---|
| L0 | Does the system still hold? | basis collapse, fake participation | stop, exit, load reduction |
| L1 | Do actions produce verified effects? | activity without effect | minimal action + readout |
| L2 | Which stories/roles gate behavior? | rationalization, taboo, shame loops | reframe + permission update |
| L3 | Which metrics/rules define reality? | Goodhart, metric theater | axis policy, anti-capture checks |
| L4 | Who can change rules legitimately? | institutional capture | governance reset, veto rights |
| L5 | Where are the regime boundaries? | delayed transition, hard crash | transition protocol |

Use this map as routing logic, not ideology.

## Quickstart (10 minutes)

<a id="quickstart"></a>

### 1) One-sentence summary

Systems tend to optimize what is cheapest to hold now, and fail where regime-holding cost stops converging.

### 2) 60-second model map

- L0: basis/existence (0/1)
- L1: action -> observable effect
- L2: narratives and role contracts
- L3: metrics/rules/axis policy
- L4: institutions and sanctioning power
- L5: boundaries and transitions

### 3) First move protocol

If "any option leads to the same failure": go depth-first (L3 -> L1 -> L0).
If causality holds but choice is unclear: go breadth-first (usually L2/L3).

### 4) Starter symptoms

- Fires everywhere, overload: start `L0-C1` (pause/stop)
- Metrics up, reality down: start `L3-C6` (break metric game)
- No clear next step: start `L1-C2` (minimal readout)
- Narrative deadlock: start `L3-C7` (axis policy)

### 5) Fast navigation

Use `Sx/Ty` and `Lx-Cn` codes from appendix navigation to jump directly to the needed operator.

## First aid protocol (when the system is melting)

Use this in emergency mode before deep analysis.

1. Freeze escalation (`L0-C1`): stop adding commitments.
2. Restore a truthful sensor (`L0-C6`/`L1-C2`): one observable that cannot be faked cheaply.
3. Remove impossible scope (`L0-C4`): reduce obligations to sustainable capacity.
4. Isolate toxic coupling (`L0-C5`): quarantine the failure amplifier.
5. Decide path:
   - if causality returns -> move to L1/L2 refinement,
   - if causality does not return -> execute transition logic (L5).

Rule:

> In emergency, survival of causality has priority over optimization of goals.

## Thesis

This book proposes an operational reading of complex systems:

1. Stability is not guaranteed by intent; it is guaranteed by convergent basis contracts.
2. Learning is not metric minimization alone; it is invariant retention under perturbation.
3. Metrics are sensors, not truth.
4. Institutional quality is measured by anti-capture and reversibility.
5. Transitions must be explicit: boundary crossing without protocol creates systemic debt.

Pragmatic consequence:
- diagnose by level,
- act with the smallest operator that restores causality,
- re-check by multi-signal readout.

## How to read this book

This is a diagnostic and operator handbook.

Reading rules:
1. Start from observed symptoms, not from favorite theory.
2. Identify active level(s) first.
3. Apply one operator at a time.
4. Validate with readout panel (never one KPI).
5. Escalate to deeper level only if current level does not restore causality.

Terminology:
- `Sx/Ty`: scene/topic code (where the symptom appears)
- `Lx-Cn`: level/operator code (what to do next)

## L0: Existence (0/1) as minimal invariant

L0 answers one question:

> Can this system still sustain causality over its current horizon?

Operationally:
- `L0 = 1`: basis contracts hold with manageable default rate.
- `L0 = 0`: basis defaults are systemic, action-consequence coupling breaks.

### Typical L0 signals

- recurrent default on basic promises,
- imitation replacing participation,
- chronic overload without recovery windows,
- silent withdrawal from key actors.

### Core operators

- `L0-C1` pause/stop,
- `L0-C2` refusal/exit as truth signal,
- `L0-C4` obligation reduction,
- `L0-C5` quarantine of toxic coupling,
- `L0-C6` restore real feedback.

### Readout panel

- basis stability rate,
- default frequency,
- participation authenticity,
- recovery window integrity.

If L0 cannot be restored, move to L5 transition logic.

## L1: Minimal operation and verified effect

L1 is the action layer.

Question:

> Which smallest action changes state in a measurable way?

### Failure patterns

- high activity, zero state change,
- long loops with no truthful readout,
- parallelism overload and hidden queues,
- post-mortems that punish people instead of fixing operators.

### Core operators

- `L1-C1` minimum viable action,
- `L1-C2` minimum truthful readout,
- `L1-C3` cycle shortening,
- `L1-C4` parallelism reduction,
- `L1-C7` "done = verified".

### Readout panel

- cycle time and variance,
- step success ratio,
- rework ratio,
- queue pressure.

L1 must stay connected to L0 constraints and L3 axis policy.

## L2: Narratives, roles, and interpretation

L2 captures social semantics:
- what can be said,
- who may act,
- what is considered legitimate.

### Typical failures

- blame theater replacing diagnosis,
- heroism normalized as default,
- taboo on stopping or dissent,
- explanation replacing experiment.

### Core operators

- explicit reframe (`L2-C5`),
- permission repair (who is allowed to pause/report truth),
- anti-taboo probes (`L2-C6`),
- shift from story to test (`L2-C7`).

### Readout

- quality of disagreement,
- ability to report bad news safely,
- ratio of experiments to explanations.

L2 is not optional: if roles forbid truth, L1/L3 degrade fast.

## L3: Metrics, rules, and axis policy

L3 defines what the system treats as reality.

Main risk:

> Goodhart: metric optimization without dynamic improvement.

### Typical failures

- dashboard growth with declining field outcomes,
- incentives rewarding imitation,
- obligation growth detached from capacity,
- hidden cost transfer to lower levels.

### Core operators

- `L3-C1` metric as sensor, not objective,
- `L3-C4` stop-rule guardrails,
- `L3-C5` return cost of errors to source,
- `L3-C6` break report theater,
- `L3-C7` explicit axis policy.

### Readout panel

- target metric + at least two independent counter-signals,
- refine/escalation pressure,
- transferability and robustness under perturbation.

## L4: Institutions, power, and anti-capture

L4 asks:

> Who can change rules, and under which legitimacy constraints?

### Failure patterns

- concentrated interpretation monopoly,
- blocked veto/stop rights,
- irreversible decisions without rollback path,
- governance serving capture rather than system resilience.

### Core operators

- distributed veto/stop rights,
- explicit rollback protocols,
- periodic legitimacy audits,
- anti-capture governance checks.

### Readout

- reversibility index,
- authority concentration indicators,
- response time to confirmed systemic defects.

L4 quality determines whether L3 corrections are possible in practice.

## L5: Boundaries, transitions, and regime change

L5 handles boundaries where old optimization stops converging.

### Typical signs

- repeated L0/L1 restoration attempts fail,
- growing intervention energy for shrinking effect,
- stable mismatch between reported and observed reality,
- structural debt accumulates faster than remediation.

### Core operators

- transition trigger criteria,
- controlled shutdown or scope contraction,
- contract renegotiation before restart,
- post-transition invariant validation.

### Readout

- transition success under fixed horizon,
- debt reduction trajectory,
- restored causality and participation quality.

At L5, the question is not "optimize more", but "change regime safely".

## Terms

- **Basis (L0)**: minimal contracts/resources that keep causality alive.
- **Readout**: multi-signal observation panel used for decision validation.
- **Goodhart mode**: optimization of a sensor that degrades real dynamics.
- **Axis policy**: explicit choice of which projections/metrics define reality.
- **Capture**: concentration of interpretation/rule power in one actor/group.
- **Transition**: explicit regime shift when current mode no longer converges.
- **Invariant**: retained class/property under perturbation.
- **Operator**: minimal action that changes state in a verifiable way.

## Invariants and tests

This checklist aligns book-level diagnostics with repo-level verification.

### Invariants

1. Causality can be measured (no blind optimization).
2. Readout is multi-signal (anti-Goodhart).
3. Basis stress is visible before collapse.
4. Rule changes preserve rollback path.
5. Transition criteria are explicit before regime switch.

### Practical tests

- reproducible headless runs (`catalog/metrics/summary/final_state`),
- trace/watch linkage (`trace_ref` continuity),
- metric-countermetric consistency,
- no hidden dependency from core (`detm/*`) to app UI.
