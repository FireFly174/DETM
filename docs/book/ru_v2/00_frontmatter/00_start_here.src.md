# С чего начать за 60 секунд (v2, черновик)

Если книга кажется одновременно простой и слишком умной, начни не с теории, а с выбора маршрута.

## Выбери дорожку

<a id="novice-lane"></a>
### Я новичок / учу ребенка

Цель: быстро понять идею без перегруза терминами.

1) Прочитай [«Быстрый старт (10 минут)»](#quickstart).
2) Возьми один симптом из раздела 4 и сделай **один первый шаг**.
3) Проверь результат через `24h` по readout.

Дальше: [«Как читать»](#how-to-read) -> `L0 -> L1 -> L5`.

<a id="practitioner-lane"></a>
### Я практик (инженер/PM/руководитель)

Цель: быстро вернуть причинность в рабочем контуре.

1) Открой [«Первая помощь»](#first-aid).
2) Зафиксируй `Sx/Ty` и выбери **один первый оператор `Lx-Cn`**.
3) Сверь ход по [5 тестам](#invariants-and-tests).

Дальше: `L0 -> L1 -> L3 -> L5` + [S-T-C шпаргалка](#nav-cheatsheet).

<a id="researcher-lane"></a>
### Я исследователь / аналитик

Цель: держать границы применимости модели и не смешивать уровни.

1) Прочитай [«Тезис»](#thesis) и [«Как читать»](#how-to-read).
2) Зафиксируй наблюдаемые входы до интерпретаций.
3) Проверь, где нужен поиск вглубь, а где вширь.

Дальше: `L0 -> L2 -> L3 -> L5` + [реестр ситуаций](#case-registry).

## Если сейчас «пожар»

Не выбирай идеальный маршрут. Делай короткий цикл:

`симптом -> тема T -> сцена S -> первый оператор -> readout 24h`.
