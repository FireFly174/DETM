# Как читать (v2, черновик)

Эта глава — не теория ради теории, а инструкция, как не утонуть в тексте.

## Цель чтения

Цель книги не в том, чтобы «объяснить всё», а в том, чтобы выбрать рабочий уровень действия:
где чинить базис, где менять правила, а где признать границу режима.

## Три маршрута

- Быстрый: `L0 -> L3 -> L5` (базис -> управление -> границы).
- Инженерный: `L0 -> L1 -> L3 -> L4 -> L5`.
- Через смыслы: `L0 -> L2 -> L3 -> L4 -> L5`.

Если ты без контекста, начинай с [«С чего начать за 60 секунд»](#start-here) и [«Быстрого старта»](#quickstart).

## Три типовые ошибки чтения

1) **Смешивать уровни.**
Когда сбой `L0`, его нельзя лечить только разговорами уровня `L3`.

2) **Прыгать сразу к выводам.**
Сначала фиксируй наблюдаемое, потом интерпретации.

3) **Оптимизировать отчёт вместо эффекта.**
Если после шага не меняется readout, это не прогресс.

## Одна диагностика: вглубь или вширь

- Иди **вглубь** (`L3 -> L1 -> L0`), если readout нестабилен или «любой выбор не меняет траекторию».
- Иди **вширь** (`L2-L3`), если причинность держится, но нужно выбрать цель/ось/тактику.

Мини-правило:

```text
if readout unstable:
    go_depth()
else:
    go_breadth()
```
